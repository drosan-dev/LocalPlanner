# Инструкции для агентов

- Документацию проекта писать на русском языке.
- Новые файлы в `docs/` вести на русском, если пользователь явно не попросил другой язык.
- Технические идентификаторы, названия классов, полей и команд оставлять в исходном виде, если перевод ухудшает точность.
- При задачах, затрагивающих UI или визуальное поведение приложения, сверяться с `docs/design-style.md` и сохранять описанный там стиль.
